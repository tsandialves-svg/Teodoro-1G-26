## 5. Conceitos novos que aprendi
 
- **Site estático:** site formado por arquivos prontos (HTML, CSS, imagens) que
  o servidor só entrega, sem processar código no servidor.
- **GitHub Pages:** serviço do GitHub que publica um site estático a partir
  de um repositório, em um endereço público.
- **Git e GitHub:** Git é o sistema de controle de versão que roda no meu
  computador; GitHub é o site onde o repositório fica hospedado.
- **Comandos básicos do Git:** `git init` cria o repositório; `git add` prepara
  as mudanças; `git commit` grava as mudanças no histórico; `git push` envia
  para o GitHub.
- **Commit:** registro de um conjunto de mudanças, com uma mensagem que explica o que foi feito.
- **Markdown:** linguagem simples de formatação de texto, usada no `README.md`.
- **Estrutura de pastas e caminhos relativos:** o `index.html` fica na raiz e o
  CSS em uma pasta própria (`css/`), ligado por um caminho relativo.
- **Publicação e teste em aba anônima:** confirma que qualquer pessoa consegue abrir o site.
